### 4.3 Mascot 眼睛（最后修的，最重要）

| 路径 | 作用 |
|------|------|
| `desktop/src/vue/components/common/mascot.png` | **主素材**（Avatar import） |
| `.../mascot-before-eyes.png` | 挖空版备份，勿当运行时资源 |
| `desktop/src/vue/components/common/MascotAvatar.vue` | canvas 重色 + mood + **轻眯眼 blink** |
| `desktop/src/vue/lib/mascotRecolor.ts` | 只染紫身；**保白眼 + 保深蓝面罩/瞳孔** |

**根因（写进文档防再踩）：**

- 旧 `mascot.png` 左右眼是 **alpha=0 透明洞**（各约 1.1 万像素），不是「染色丢了眼白」。
- 深色办公室底上一看就像眼球被挖掉。
- 旧 `isPreserveDark` 只保 RGB&lt;55，**面罩 ~57,65,172 被当成 purpleish 一起染色** → 粉/橙角色更像黑洞。

**已做修复：**

1. 用原洞轮廓填白眼 + 深蓝瞳 + 高光；洞像素归零  
2. `isPreserveWhite` 放宽（含偏蓝高光）  
3. `isPreserveDark` 覆盖 navy 面罩/瞳孔  
4. blink：`scaleY(0.08)` → `0.55`，原点靠上，避免整脸压成黑缝  
5. 单测已更新；`vite build` 已出新 hashed mascot
